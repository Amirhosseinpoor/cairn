# ADR-0017: Terminal color

- **Decision:** D-17 (SPEC §2.1)
- **Status:** Accepted (2026, Cairn 1.x)
- **Category:** Technology

## Context

Color in Cairn is not a one-setting concern: the terminal compatibility matrix (§10.7) spans
truecolor, 256-color quantization (nearest-CIE76), 16-color semantic mapping, `TERM=dumb` plain
mode, `NO_COLOR` (colors off), and `CLICOLOR_FORCE=1` (forced in pipes). Color is also a
configuration surface (`--no-color` / `NO_COLOR` / `ui.color`, §11.1) and an accessibility
constraint: the high-contrast theme pairs every status with a symbol so color is never the only
signal (REQ-TUI-009, §10.8). Cairn's theme system owns the palette and syntax/mode colors
(§10.5 theme TOML), so styling must be semantic (accent/green/amber/red/blue, mode pills), not
hard-coded SGR sequences. The TUI writes raw SGR while logs take ANSI (§12.1 human-readable
stderr), and both must honor the same theme decisions.

## Decision

Use **`anstyle`/`owo-colors`-style semantic styles owned by Cairn's theme system (raw SGR in the
TUI, ANSI in logs)**. Per the spec's rationale: this is what `NO_COLOR`, truecolor/256/16 fallback,
and the high-contrast theme require.

## Alternatives rejected

| Alternative | Why it was rejected |
|-------------|---------------------|
| `colored` crate | Not chosen; a general-purpose color crate does not own the semantic theme layer Cairn needs for `NO_COLOR`, truecolor/256/16 fallback and the high-contrast theme (spec's stated rationale for the choice). |

## Consequences

- Positive: one semantic style layer backs every degradation path in §10.7 and is snapshot-assertable — T-TUI-030 (`NO_COLOR=1`, no SGR bytes), T-TUI-031 (`TERM=dumb`), T-TUI-032 (16-color mapping), T-TUI-033 (high-contrast + symbol-not-color-only).
- Positive: `NO_COLOR`/`CLICOLOR_FORCE`/`ui.color` remain the single controls across TUI, logs and headless output (§11.1, §10.7).
- Risks / costs: two emission paths (raw SGR in the TUI, ANSI in logs) must both route through the theme system, or styling drifts between surfaces.
- Risks / costs: legacy terminals keep partial support — conhost renders 16-color only and warns `W-TUI-CONHOST` (§10.7), so style fallbacks must remain tested, not assumed.
