# ADR-0003: TUI framework

- **Decision:** D-03 (SPEC §2.1)
- **Status:** Accepted (2026, Cairn 1.x)
- **Category:** Technology

## Context

The interactive TUI is Cairn's primary interface: six canonical wireframes (§10.1), approval
prompts, a diff viewer, a plan card, streaming with a 60 fps cap (REQ-TUI-007), and a terminal
compatibility matrix spanning truecolor/256/16-color/`TERM=dumb`, tmux, SSH, Windows Terminal and
legacy conhost (§10.7). Rendering must use the alternate screen and restore both screen and cursor
on exit *and* on panic (REQ-TUI-002).

Testing determinism is a hard requirement: the wireframes and the error/empty/loading states of
§10.9 are golden-screen snapshot tests (T-TUI-001..006, T-TUI-010..019) captured through a PTY
harness with a compact per-cell style encoding (§14.5). The framework must also handle Windows
conhost and Unix terminals, alternate screen, mouse capture, bracketed paste and SIGWINCH resize.

## Decision

Use **`ratatui` 0.29 + `crossterm` 0.28**, versions frozen at M0 (§15.2). Per the spec's
rationale: immediate-mode rendering yields deterministic snapshot testing, and crossterm handles
Windows conhost + Unix, alternate screen, mouse capture, bracketed paste and SIGWINCH resize. The
alternate screen is entered at startup and restored on `Drop`/panic hook (REQ-TUI-002).

## Alternatives rejected

| Alternative | Why it was rejected |
|-------------|---------------------|
| `termwiz` | Smaller community, fewer examples. |
| `tui-rs` | Dead project. |
| `bubbletea` | Written in Go; does not fit the Rust workspace chosen in D-01. |
| Raw ANSI by hand | Reimplements what crossterm already provides (platform terminal control, resize, paste, mouse). |

## Consequences

- Positive: golden-screen tests over text + style maps stay deterministic (§14.5; T-TUI-001..006, T-TUI-040).
- Positive: one input/event layer covers the whole §10.7 matrix, from Windows Terminal down to legacy conhost.
- Risks / costs: dependency versions are frozen at M0 (§15.2), so a framework upgrade is a deliberate, spec-level change.
- Risks / costs: legacy conhost keeps a documented limitation (16-color only, no mouse, warns `W-TUI-CONHOST`, §10.7) — terminal quirks remain Cairn's problem to render around.
