# ADR-0004: HTTP & streaming

- **Decision:** D-04 (SPEC §2.1)
- **Status:** Accepted (2026, Cairn 1.x)
- **Category:** Technology

## Context

All five adapters (Anthropic, OpenAI, OpenAI-compatible proxies, Ollama, vLLM — §4.2) speak SSE or
NDJSON, and streaming is the only supported mode (§3.4, `Provider::stream`). The parser contract in
§4.3 is demanding: split on `\n\n` / `\r\n\r\n` boundaries that do not align with read sizes, retain
partial lines across reads, join multiple `data:` lines, cap a single event at 1 MiB
(`E-PROV-EVENTBIG`), tolerate malformed chunks, reset an idle timer on heartbeat comments, abort
after 45 s of silence (`E-PROV-IDLE`), and abort the HTTP body within 250 ms of cancellation.
`id:`/`retry:` are recorded but unused — there is no auto-reconnect replay (§4.3 rule 2; see
ADR-0020).

TLS must work without OpenSSL (§15.2: rustls, no openssl), while still handling proxies, HTTP/2,
gzip and timeouts. Cairn also ships a static musl binary (§2.2), so avoiding a system TLS
dependency matters for the artifact matrix (REQ-PROD-001).

## Decision

Use **`reqwest` 0.12 (rustls, no default roots → bundled Mozilla roots) plus a hand-written SSE
parser as the internal `cairn-sse` crate** (§15.1). Per the spec's rationale: a bespoke
~300-line SSE parser gives exact control over partial lines, CRLF, `id:`/`retry:` fields, idle
timeout and mid-stream cancel, while reqwest provides proxy, HTTP/2, gzip and timeouts.

## Alternatives rejected

| Alternative | Why it was rejected |
|-------------|---------------------|
| `eventsource-stream` | No idle timeout hooks. |
| `hyper` raw | Reimplements redirects/proxies. |
| `ureq` | No streaming. |

## Consequences

- Positive: every §4.3 parser rule (partial-line retention, 1 MiB cap, malformed-chunk recovery, idle timeout, 250 ms cancel abort) is directly implementable and testable against the raw byte fixtures in `tests/fixtures/streams/` (§14.1).
- Positive: `cairn-sse` is an isolated crate (§3.2: may import only tokio/bytes/thiserror), so parser behavior is unit-testable without any provider.
- Risks / costs: the parser is bespoke code Cairn maintains; its edge cases (CRLF, torn lines, unknown events) must stay covered by fixtures and fault tests (T-PROV-006, T-FAULT-003).
- Risks / costs: there is no reconnect replay by design (§4.3 rule 2) — mid-stream recovery is delegated to the retry matrix (§4.5) and the resume decision recorded in ADR-0020.
